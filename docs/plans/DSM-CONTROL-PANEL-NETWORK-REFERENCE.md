# DSM控制面板与网络管理参照

2026-10-16，用户要求详细参考群晖DSM控制面板和各种网络管理功能。本文件把这一要求落实为页面结构、能力缺口、macOS适配工作和验收流程；与[整体功能差距](DSM-FUNCTIONAL-BASELINE.md)、[文件浏览阶段](N-023-FINDER-STYLE-FILE-BROWSING.md)共同约束后续开发。

资料以群晖官方DSM 7.4技术规格和明确标注版本的帮助文档为准。这里不是已完成清单，也不是所有DSM能力均纳入首版的承诺。现有111父需求、97项首版/13项后续/1项暂不需要保持不变；对于原需求没有明确覆盖的企业或路由器功能，先做兼容性调研，不擅自升级优先级。没有登录群晖、操作路由器或改变这台Mac的网络设置。

用户随后直接新增SYS-09网页远控Mac，并明确很后期，另存[补充账目](../../requirements/user-additions.json)及[后期计划](FUTURE-WEB-MAC-REMOTE-CONTROL.md)。当前合并有效112项；该新增不改变本文件的先文件管理/控制面板、后远控顺序，也不授权现在启用远控或扩大系统权限。

## 1. 当前缺口与控制面板结构

当前“设置”主要提供演示身份、语言、主题和桌面偏好。没有生产账户管理、共享配置、网卡/IP/DNS/路由管理、证书管理、防火墙、远程接入或服务端配置事务。Swift/PostgreSQL原型中的角色、资料库、审计和任务，不等于这些控制面板业务已经接线。

MacNAS的控制面板拟按以下用户目的组织，每个页面显示能力状态和数据来源，未接通的能力不得显示“已启用”或虚假的保存成功：

|分组|页面|用户要完成的事|现有需求落点|
|---|---|---|---|
|共享与访问|共享文件夹；文件服务；用户与群组；有效权限|管理谁能通过网页、Finder/SMB访问哪些资料，解释拒绝原因|SHR-01至SHR-10、SEC-06/07|
|连接与入口|网络概况；接口；DNS与路由；代理；远程访问；登录入口|辨认实际访问地址、连接状态及故障位置，预演受控变更|SEC-01/02/03/04/10、SYS-01/05、OPS-07|
|安全|会话与MFA；证书；访问规则；登录保护；审计|保护管理面、撤销会话、检查配置变化与异常登录|SEC-02至SEC-09、OPS-01|
|系统|系统信息；时间与地区；通知；任务计划；更新与配置恢复；硬件能力|知道系统是否正常、计划何时执行、如何恢复设置|SYS-04/05/06、OPS-01/02/03/05/07/08、BAK相关项|
|关联应用|存储管理器；资源监控；日志中心；套件中心；备份恢复|从设置跳到完整应用流程，避免控制面板塞入所有业务|STO、APP、BAK各既有需求|

管理员、只读家庭成员、只读恢复模式必须得到不同的可见范围和操作权限；隐藏按钮只是展示策略，后端仍逐项授权。目录服务、DNS/DHCP服务器等扩展项的落点是兼容调研，不能据此宣称已有首版需求。

## 2. 网络：逐页对照与MacNAS交付要求

DSM的网络规格包含地址接入、VPN、IPv6、网关/DNS、代理、VLAN、链路聚合、流控和静态路由；外部访问另含DDNS与QuickConnect。具体协议、数量和硬件限制以[官方网络与外部访问规格](https://www.synology.com/en-global/dsm/7.4/software_spec/network_external_access)为准。下面是MacNAS自己的页面与验证设计，不承诺照搬DSM的Linux网络栈。

|页面/能力|MacNAS需要呈现或实现|macOS适配与边界|最低验收流程|
|---|---|---|---|
|网络概况|接口与服务对应关系；当前可用的局域网入口；采样时间、来源、故障原因|区分计算机名、接口名和网络服务名；不能以某个固定en0代表全部Mac|合成多网卡、无地址、接口消失；过期数据明确标记；无探测数据不得显示连接正常|
|物理与虚拟接口|网口类型、链路状态、已知速率、MTU、IPv4/IPv6地址及归属；接口详情|只读采集器先行；以系统稳定标识绑定配置，区分USB网卡、Wi-Fi、桥接和VPN；权限不足返回未知|USB网卡拔出/重接、接口重命名、同名不同硬件、数据部分缺失不混淆|
|IPv4|DHCP/手动配置、地址/前缀、网关；变更前后差异|应用配置不等于生效配置；验证地址/子网关系；特权变更依赖尚未实现的系统helper|用合成配置检查非法/重复地址、网关不在链路、管理入口迁移；失败保留原设置|
|IPv6|自动/手动方式、前缀、链路本地地址及作用域、多地址状态|IPv6不能仅附加一个文本框；必须保留接口作用域、临时地址和默认路由归属|IPv4正常/IPv6失败、双栈、多IPv6、链路本地入口都能正确解释；不误报整体断网|
|DNS客户端|系统解析器、按服务或域生效的DNS、搜索域；指定名称的诊断结果|系统解析器与应用自行解析不同；先只读显示，不覆盖VPN或其他应用的分域DNS|模拟不可达、NXDOMAIN、超时、分域DNS；把DNS失败与IP不可达区分；诊断结果有时间与目标|
|默认网关与服务顺序|当前默认路径、候选服务优先级、多网卡出口|配置网关与内核实际路由分开展示；不可假定修改服务顺序必然切换所有连接|两个网口/两条默认路由/VPN覆盖时说明实际路径；旧快照不可覆盖新状态|
|静态路由|目标CIDR、网关、接口、现有规则与拟变更差异|系统helper管理有归属的规则；不能清空或接管其他软件创建的路由；持久性另做验证|拒绝非法CIDR、不可达下一跳、重复/重叠歧义；回滚只撤销本次规则|
|MTU、VLAN、802.1X|能力探测、当前状态及支持条件；高级设置独立分区|驱动/硬件/系统版本差异需查证；不默认支持DSM全部模式；证书/凭据只引用受控秘密|不支持时给出原因；合成断链、交换机不匹配和凭据过期；真实变更须独立环境验收|
|聚合、桥接与故障切换|成员接口、模式、有效链路、不可兼容条件|DSM Bond模式不直接映射macOS；桥接、聚合、SMB多通道是不同能力；先探测可用性|成员退出/恢复、硬件替换、冲突配置；不能把总链路速率当单次传输速率|
|出站代理|HTTP/HTTPS、绕过列表、凭据引用、影响哪些MacNAS组件|应用代理与系统代理分开；秘密不进入URL/日志/导出；不覆盖用户全局代理|本地绕过、认证失败、代理不可用；无静默直连回退；测试只访问明确目标|
|带宽与连接|应用任务限速、活跃传输、连接状态；系统流量图另列|先在自有传输任务中实现预算；不冒充整机QoS，不默认操纵系统包过滤/整形|限速、暂停、取消、突发与并发公平性；采样计数不是精确计费；边界有测试|
|网络诊断|明确目标的DNS、路由、端口/服务检查与脱敏结果|不做全网扫描；诊断与配置写入分离；没有目标授权时不主动探测家庭设备|使用合成适配器覆盖超时/部分成功/权限不足；导出不包含秘密或无关设备清单|

### 远程访问和登录入口

|能力|MacNAS设计要求|实施条件与失败处理|验收|
|---|---|---|---|
|局域网发现|显示可连接入口；区分发现广告与实际可达性|Bonjour/WSD等先做平台适配，不将loopback预览冒充NAS服务|多地址、地址过期、端口冲突、未授权发现分别覆盖|
|DDNS|供应商、域名、最后更新时间、错误与秘密引用|不内置或冒充Synology账户服务；供应商/组件单独准入；变更有任务与审计|更新成功/限流/凭据撤销/地址变化，日志和配置导出无token|
|私有远程通道|明确服务范围、连通状态、用户与撤销流程|SEC-10既有要求；现有VPN产品/系统扩展先评估，不能自动安装依赖或加入网络|授权设备可达、撤销后失效、客户端退出、DNS与路由污染检查|
|外网映射|端口、来源网络、对应服务和暴露范围|不自动开启UPnP或修改路由器；防火墙、IPv6直达和NAT各自判定|只做隔离环境演练；关闭入口后的验证与回滚记录完整|

|反向代理|来源域名/协议/端口、目标、超时、WebSocket、规则顺序、访问条件|只允许已授权服务目标，防止任意内网代理；配置校验成功后才切换|路由冲突、不可达上游、证书失效、超时、规则撤销、旧配置保留|
|证书与服务分配|域名、签发方、有效期、续期状态、绑定服务、密钥引用|先验证证书/链/域名/密钥匹配；续期不自动扩大网络开放；Keychain接入尚未完成|到期、域名不符、链不完整、续期失败保留有效旧证书；导出不泄露私钥|

门户、别名、端口和反向代理的DSM参考分别见[登录门户](https://kb.synology.com/en-af/DSM/help/DSM/AdminCenter/system_login_portal?version=7)及[高级设置与访问规则](https://kb.synology.com/index.php/th-th/DSM/help/DSM/AdminCenter/system_login_portal_advanced?version=7)。MacNAS不会提供一个仅改名称、却没有可用认证和服务路由的假入口。

## 3. 共享、账户与文件服务

DSM区分用户/组、共享权限、应用权限和外部目录身份，具有明确的拒绝/允许优先关系；[官方账户与权限规格](https://www.synology.com/en-global/dsm/7.4/software_spec/account_identity_privileges)是功能参照。MacNAS自己的ACL语义需与macOS及实际SMB行为一致，不能直接把DSM优先级文字当实现。

|页面|MacNAS交付要求|当前状态与适配工作|验收|
|---|---|---|---|
|用户与群组|用户生命周期、组成员、个人资料库、会话撤销和应用权限|仅有合成administrator/reader；系统账户与网页账户映射尚无实现；SHR-05、SEC-06/07|停用用户后新请求拒绝；旧会话撤销；不能因改显示名改变授权主体|
|共享文件夹|路径绑定、在线/离线、网页/SMB用途、权限、回收站、变更预览|现有资料库为逻辑fixture；真实共享发现、创建、冲突处理及撤销缺失；SHR-01/02/03|相同显示名不同卷、掉线/重绑、拒绝越界路径、失败不改旧共享|
|有效权限|按用户解释继承、组、显式规则以及各操作是否允许|只读解释先行，编辑ACL需平台适配；SHR-04/06、SEC-07|网页与SMB对同一合成授权一致；拒绝原因可解释；陌生用户/路径不泄露信息|
|SMB|已存在服务只读发现、共享列表、当前连接；接管后才提供受控设置|不启动/重配macOS现有SMB；版本、签名、加密、多通道、文件锁等能力逐项探测；SHR-01/08/09|Finder与Windows客户端分别测试，断线重连、锁冲突、Unicode文件名、权限撤销|
|Time Machine|共享用途、容量策略、客户端可见性与状态|SHR-07独立验收；不能以普通SMB共享或Bonjour广播当备份完成|真实客户端首次备份、继续备份及恢复须独立阶段，当前未执行|
|NFS/FTP/SFTP/WebDAV/rsync|每协议分别列能力、端口、用户范围、日志和依赖|SHR-10/备份相关项；不将一个通用启用开关冒充全部协议；不自动开放SSH|每协议都有认证失败、只读、路径越界、取消和连接关闭测试；新组件先准入|
|AD/LDAP/SSO|列出与本地账户的区别及兼容性调研结果|不是既有首版承诺；需身份映射、离线缓存、秘密/证书管理及撤销设计|若获准进入范围，再测嵌套组、断网、同名不同主体、目录撤销|

文件服务的参照见[官方协议规格](https://www.synology.com/en-global/dsm/7.4/software_spec/file_services_protocols)。其中SMB、NFS、FTP/SFTP、rsync等有各自限制和硬件条件；MacNAS不继承DSM的连接数量、Linux模块或特定文件系统优化承诺。

## 4. 安全与系统管理

DSM有登录会话、MFA、账户保护、自动封锁、防火墙与证书等不同层次的控制，见[安全与登录保护规格](https://www.synology.com/en-global/dsm/7.4/software_spec/signin_protection)。MacNAS必须区分应用登录限流、来源访问规则和主机防火墙，不能用网页按钮假装完成整机保护。

|页面/功能|MacNAS实施内容|当前缺口与验收要点|
|---|---|---|
|会话与MFA|登录/退出、活动会话、超时、撤销、恢复路径、敏感操作再次验证|生产认证缺失；必须测试时钟偏差、会话固定、撤销、丢失第二因子的恢复；合成开发会话不得升级为生产凭据|
|账户保护与封锁|失败计数、限流、例外、过期、审计；不暴露账户是否存在|尚无生产登录；共享出口/反向代理下区分用户和可信来源；解除封锁有审计|
|防火墙与访问规则|当前策略只读展示、规则顺序、来源CIDR、端口、默认动作、所属组件|macOS应用防火墙与包过滤不同，helper与所有权仍缺失；禁止清空系统/他人规则；必须具备管理入口失联后的恢复方案|
|系统信息与资源|实际硬件/OS/服务版本、CPU/内存/磁盘/网络采样、连接与任务|当前网页无真实指标；数据有采样时刻、单位、未知和过期状态；不能把合成35TB当实盘容量|
|日志中心与审计|按时间/级别/组件/操作者/关联任务筛选，保留与脱敏导出|原型审计与生产日志分开；测试截断、磁盘满、越权、保留期；禁止原始秘密进入事件|
|通知|事件规则、去重、静默、严重级别、投递渠道与失败状态|N-022只是fixture事件来源核对；邮件/push/webhook尚未接入；渠道测试与真正发送必须显式可辨|
|任务计划|周期、时区、错过处理、并发、停用与执行历史|持久任务原型不能替代计划调度；不允许网页任意root脚本；测试重启、夏令时和重复触发|
|时间与地区|时区、系统时间状态、时间同步来源；网页语言另列|只读先行；改系统时钟会影响认证/证书/任务，需helper和配置事务；不默认新增NTP服务器|
|更新与配置恢复|版本兼容、下载校验、预演、配置导出、恢复差异和回退|现有升级/迁移只在合成环境；配置备份不能夹带私钥，也不能冒充用户文件备份|
|外接设备与电源|设备清单、挂载状态、可安全移除条件、硬件能力说明|macOS/硬件差异需验证，不自动调风扇/LED/休眠；UPS依旧OPS-06暂不需要；不能因DSM存在就加入首版|

资源、日志、通知和任务的参照是[系统运行与监控规格](https://www.synology.com/en-global/dsm/7.4/software_spec/system_operations_monitoring)。时间同步的参照见[DSM NTP服务](https://kb.synology.com/index.php/da-dk/DSM/help/DSM/AdminCenter/system_ntpservice?version=7)；MacNAS只读显示、未来配置以及新建服务器是三个独立范围。

## 5. 配置变更必须形成完整流程

以下是MacNAS实现要求，尚未实现的系统helper、权限和生产配置事务不得标为完成：

1. 先读取当前配置及来源版本，用户编辑草稿；页面明确“当前生效”“待应用”和“读取失败”。
2. 后端验证权限、目标身份、平台能力、字段关系与端口/路由冲突，给出差异、影响的服务、可能失联的管理入口及恢复办法。
3. 执行前再次检查源版本，避免旧页面覆盖其他工具的改动；多个配置任务按资源序列化。
4. 只修改归属本项目且获准的配置。新凭据进入受控秘密存储，数据库保存引用；操作日志关联任务和操作者并脱敏。
5. 记录应用/验证/回滚阶段；网络变更依赖独立本机恢复通道与超时回退，不能依靠已经断开的网页连接确认成功。
6. 读取实际生效状态进行验证，失败保留可解释原因；回滚失败也必须可见。不要仅凭命令退出码或页面刷新就显示完成。

## 6. 接续顺序与验收门槛

|顺序|可交付流程|完成条件|
|---|---|---|
