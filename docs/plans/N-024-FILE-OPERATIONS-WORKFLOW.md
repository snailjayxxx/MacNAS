# N-024：文件操作与传输流程

接续N-023，按用户“像Finder浏览文件、更多参考DSM”的要求推进实际业务，不再只扩展通知后端小模型。文件中心尚缺写入、传输与生产连接，本阶段先设计并实现可验证的一条受控操作流程；实际范围须在接续读完现有目录/文件边界后确定。

## 优先交付

从“选择有权资料库与目录 → 创建文件夹/重命名 → 冲突预览 → 提交任务 → 查看结果与错误 → 重新读取目录”开始，随后依次补上传/下载、复制/跨卷移动和回收站。不要一次放置一组不可用或假成功按钮。后台结果、权限、取消/重试和失败恢复是流程组成，不只是弹窗。

## 必须解决的边界

- 继续使用显式批准的合成目录和独立fixture；真实NAS、系统账户/ACL/SMB接管及家庭文件不在自动授权内。
- 文件名与相对路径校验、卷/介质/挂载批准、符号链接/硬链接及竞态边界必须重新审查；现有只读描述符方案不能未经证明扩展为安全写入。
- 任务幂等键绑定当前身份、原目录版本和意图；名称冲突、目录变化、撤权、缺卷、取消及提交后响应丢失都需可解释结果。跨卷移动不能先删源再验证目标。
- 先有真实核心/管道证明，再接具名客户端和合成网页流程；固定的内存演示不作为落盘/权限证明，也不新增生产API监听。
- 生产HTTP宿主、认证/会话、系统helper与配置事务仍为独立前置，不能用localStorage身份或合成签名上下文代替。

## 与控制面板接续

并行推进的范围限于设计与独立只读适配器：按[DSM控制面板与网络对照](DSM-CONTROL-PANEL-NETWORK-REFERENCE.md)落实网络/服务概况、账户/共享/权限解释及未知/过期状态。不在当前Mac上修改IP、DNS、路由、代理、证书、防火墙或SMB设置。SYS-09网页远控按用户要求很后期，当前不实施。

## 验收

原生/数据库/管道、模型、静态策略、实际DOM和真实部署分别留证；浏览器权限仍未恢复时继续保留W/T/N/F未执行。可完成不依赖浏览器的安全工作，但不得给出网页或真实NAS功能已通过的结论。111项v0.6基线与用户新增SYS-09独立追踪，当前有效112项。
