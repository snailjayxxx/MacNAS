# SYS-09：网页内控制Mac桌面（很后期）

2026-10-16用户直接新增：在MacNAS中以类似远程桌面的方式查看并控制Mac本身，避免身边没有VNC客户端、无法安装客户端或当前环境不便使用时，特殊操作仍必须到电脑旁完成。用户随后明确“作为很后期的需求”。本轮只登记与记录设计条件，不开发远控代码、不安装组件、不启用系统屏幕共享/录屏/辅助功能或新监听。

## 排期与账目

## 用户流程目标

1. 管理员登录MacNAS，在授权的安全入口打开“Mac远程桌面”，查看目标主机、系统权限和可用状态。
2. 创建短时远控会话，先看到真实桌面，再明确进入键鼠控制；用户不必另外安装VNC客户端。
3. 完成必须进入macOS界面的维护，再结束会话；页面关闭、超时、身份撤销或目标切换都停止输入与屏幕流。
4. Mac本机可见远控进行中并能随时停止；支持显式无人值守配置的前提是已完成系统侧授权，具体产品方式留到后期设计。

浏览器方式解决客户端安装限制，不承诺突破当前网络/组织对远程控制的限制。Mac关机、系统或MacNAS完全不可用、网络断开时，本服务不能提供带外救援。首次系统授权、锁屏/登录窗口、FileVault启动前界面、受保护窗口和系统确认的能力必须分别验证，不能把普通桌面控制推断为任何界面都能远程完成。

## 后期技术评估

- 原生画面采集优先评估Apple ScreenCaptureKit，键鼠控制评估受支持的系统事件/辅助功能接口；Swift宿主与浏览器展示/输入协议分离，用户权限和屏幕状态由原生代理确认。
- Apple要求应用获取屏幕录制权限；通过辅助功能控制Mac也需要明确授予访问。权限诊断与引导要在初次部署时完成，不绕过TCC/SIP或自动批准系统提示。参考[屏幕录制权限](https://support.apple.com/guide/mac-help/control-access-screen-system-audio-recording-mchld6aa7d23/mac)、[辅助功能访问](https://support.apple.com/guide/mac-help/allow-accessibility-apps-to-access-your-mac-mh43185/mac)、[ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit/capturing-screen-content-in-macos)和[Quartz事件](https://developer.apple.com/documentation/coregraphics/cgevent)。这是可行性方向，不是已验证实现。
- 评估浏览器媒体流/低延迟输入与成熟网关方案的维护、许可、CPU/带宽和安全成本；协议和第三方组件尚未选定，不默认引入noVNC、WebRTC原生库、TURN或公网中继。
- 普通网页账户权限不能自动获得整机控制；该能力单独授权给管理员，敏感入口再次验证，使用短时会话/独占控制租约、来源限制与立即撤销机制，控制消息不接受任意shell或脚本。
- 画面与输入是独立权限；审计记录会话开始/结束、控制权与失败原因，默认不录屏、不记实际键入内容或密码。剪贴板、文件传输、音频和多用户同时控制不自动加入范围。
- 多屏、缩放/坐标、键盘布局、中日文IME、浏览器保留快捷键、触屏及低带宽降级需单独处理；输入限速、序号、过期与断线释放按键避免重复点击或粘键。

## 开始实现的前置

现有文件管理、控制面板及核心NAS流程先交付；生产认证/会话撤销、TLS/安全远程入口、原生代理身份和权限模型先完成。对目标macOS版本做隔离环境试验后再确定方案与阶段，不提前启动真实录屏、监听或远程输入。

## 未来验收条件（当前全部未执行）

- 不安装VNC客户端的受支持浏览器可完成查看、单击/双击、滚动、拖动和键盘；多屏坐标正确，中日输入及保留快捷键有可解释行为。
- 拒绝/撤销录屏或控制权限时停止对应能力并清晰诊断；无权限、普通家庭成员、过期/撤销会话和伪造消息不能看到屏幕或注入输入。
- 关闭/超时/断网/主机重启/切换目标时释放控制权，迟到帧及输入不落到新会话；本机停止按钮立即生效。
- 登录/锁屏/快速用户切换/无显示器/休眠/系统授权窗口逐项验证，并说明真实支持范围；macOS15与届时当前版本分别留证。
- 测试传输加密、来源校验、防重放、并发控制、速率与资源预算、审计脱敏及第三方依赖；不得为远控降低已有NAS账户、系统或网络保护。
