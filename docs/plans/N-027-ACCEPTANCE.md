# N-027：单文件复制与资源回收验收范围

日期：2026-10-16。[设计](../decisions/ADR-020-bounded-file-copy.md) · [阶段结果](../evidence/n027-2026-10-16.json)。当前阶段仅有界合成文件操作，不是生产NAS或持久文件任务。

- 原生：独立宿主复制批准、固定两端、同设备常规单链接文件、32KiB分块、16MiB单文件、私有暂存与双重摘要、RENAME_EXCL不覆盖、来源不删除；冲突、同源同目标、来源/父目录/权限变化、取消、到期、预留及结果回收。本次发布流程内的文件/授权复查、同步或期限失败为uncertain并保留目标；响应编码或传输失败可能保留completed回执，需查原ID核对。
- 协议：5个严格固定方法，真正布尔确认、未知/额外字段及任意根路径拒绝；预览编码失败不登记，发布响应丢失可显式核对，状态观察不创造执行能力，重放不重复效果。
- 真实管道：实际具名JavaScript客户端与控制器经stdin/stdout调用独立Swift测试宿主，在明确批准的新建合成目录检查二进制、空文件、取消和结果；测试宿主负责磁盘核对，不能称为浏览器到NAS连接。
- 网页模型：全树64MiB包括初始UTF8文本、各库已发布二进制、上传/复制预留；争用预算和发布转换，失败/取消/过期只释放未发布预留，已发布字节继续计量；会话结束/目录来源dispose清理该树；两端固定、不覆盖与旧目录页失效。
- 生命周期：上传预览、下载头、复制预览未返回时关闭窗口或来源，迟到能力最终释放本地所有权并尽力取消宿主；已有自有能力同样清理，同ID在途操作完成后再清理，陌生status不登记所有权。反复中断不耗尽40条本地头。保留共享连接，不自动重连、扩大预算或声称回滚。
- 展示：目标资料库与有界目录选择器、原路径/目标/大小预览、明确确认、进度、安全块边界取消、不确定结果只读核对。DOM元素替身覆盖标签/状态、普通文本和迟到目录游标回收，不包含浏览器布局/键盘/焦点。

修改原生及嵌入Node依赖后执行新的未过滤全量Swift、全部独立CLI管道/CLI演练与前端检查。每轮记录实际失败、源码摘要和测试库正常关闭。旧253项只是历史基线，不代替本轮完整回归。

原46项及FC01–FC06，共52项实际浏览器用例全部待正规权限恢复。没有新权限变化，不重复请求或启动预览；沿用8766白名单授权的范围，不扩为API/NAS服务。尚未交付目录/批量/覆盖/跨设备复制、移动/删除/回收站、GB级、重启恢复、生产身份/helper/ACL或真实NAS。Intel支持留待以后，网页远控仍很后期。
