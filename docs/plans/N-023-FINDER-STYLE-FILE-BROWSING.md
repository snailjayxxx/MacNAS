## 产品目标

用户能在已授权NAS资料库中连续浏览文件夹、辨认当前路径、往返之前的位置、选择文件并查看详情。目录内容是主工作区；演示每页3项和开发验证提示不能成为最终文件浏览体验。

## 本次基础交付

- 侧栏展示有权资料库和当前目录的直接子目录，可从任何已知路径回到资料库根目录；不预先递归扫描整个NAS，不伪造未加载目录树。
- 工具栏支持后退、前进、上一级、重新读取；路径面包屑可逐级进入。前进历史在进入新位置后截断；历史、选择与预览随身份切换清理。
- 普通文件夹默认每次读取50项，保持原有后端100项/页和目录预算；不再把3项/页作为正式交互。大目录明确显示继续读取与已加载范围，不将当前页排序/过滤冒充全目录搜索或全局排序。
- 可切换列表/图标视图；文件夹优先、名称/大小/类型的可解释排序；普通文件名保持原文，未知时间和容量不伪造。
- 单击选择、双击或Enter进入目录/打开已支持的只读文本预览；显示所选条目的路径、类型、已知大小等详情。选择与预览绑定当前目录/身份，迟到响应不能盖到另一个目录。
- 中日文、窄屏、可见焦点及键盘路径要有明确检查项。模型与静态策略验证之外，真实DOM/视觉仍必须等待正规浏览器入口恢复。

## 完整文件管理器的后续范围

真实NAS连接、授权目录接入、服务端全目录排序/搜索、虚拟滚动及大目录规模需要各自实现与验证；当前只读原型尚不代表可部署的Finder替代品。上传/下载、建目录、重命名、复制/移动、回收站和删除按既有父需求继续开发，接入权限、任务进度和恢复机制，不把模拟按钮当已实现的文件操作。照片/视频等预览也不能由当前64KiB文本预览冒充。

## 验证

覆盖跨资料库/目录的后退前进、上一级与面包屑、错误后原位置保留、选择与预览废弃、分页边界、列表/图标一致内容、排序与未知元数据、身份切换、无多余后台请求。新增浏览器专项须与W/T/N/F的历史待测记录一起保留；不能因模型测试通过而打勾。
