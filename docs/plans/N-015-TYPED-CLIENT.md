# N-015桌面业务DTO与有界客户端

已实现bridge-client.js的10个具名业务方法、完整展示数据校验、宿主身份固定、独立请求前缀、超时/关闭/取消、迟到响应丢弃及显式业务幂等意图。固定文案键与普通标题/文件名/文本区分，不伪造更新时间或物理容量。

客户端新增21项负测，与原22项合计43项；真实Node→Swift→私有PostgreSQL管道扩展到7项。前置定向轮次通过10项解析器和全部CLI/7项集成；最终全量与前端结果见[验收范围](N-015-ACCEPTANCE.md)及[结构化证据](../evidence/n015-2026-10-15.json)。

取消仅结束客户端等待并通知传输，不能证明已提交数据库操作未发生。显式意图保留id/key/value，重连后用原业务键/值重试；已提交响应被扣留的真实测试验证只返回原任务。数据与生命周期细节见[ADR-009](../decisions/ADR-009-typed-desktop-client.md)和[DESKTOP_API](../contracts/DESKTOP_API.md)。

静态页面尚未加载新客户端，浏览器传输/DOM接线、生产身份与宿主信任、真实文件授权和大规模分页未实现。[窗口验收](../../web/tests/BROWSER_ACCEPTANCE.md)按用户最新要求保留到回家，W01–W10和完整清单全部待测。
