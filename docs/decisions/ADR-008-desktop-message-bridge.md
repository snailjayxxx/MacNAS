# ADR-008：绑定宿主会话的无监听桌面消息桥接

2026-10-15（Asia/Tokyo）。实现范围为合成 CLI 的标准输入输出、Swift 分发器和 JavaScript 通用客户端。实际浏览器连接、生产认证和部署尚未实现。

DesktopBridge 构造时接收已存在的 PrototypePlatformAPI 和 fixture 会话，验证数据库为 Schema 3，并取得该会话的生命周期管理责任。请求不能创建身份或选择用户、角色、模式、数据库、根路径和系统授权。close/进程退出使会话失效；业务 API 继续逐次检查会话、资源与只读模式。业务已入队任务不会因桌面断开而取消。

消息采用 apiVersion=1、requestId、method、params，按固定方法表分发。独立有界 JSON 解析器保留数字原文，拒绝重复解码键、非法 UTF-8、孤立代理项、尾随内容和未知字段；协议整数只接受 JavaScript 安全范围内的十进制无符号整数，布尔值、分数和指数写法不混用。依据为 [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259) 的语法与重复成员互操作性问题；这里选择明确拒绝重复键。Swift 字符串的规范等价键也视为重复，避免不明确的成员选择。

请求最多 64 KiB、16 层、4096 个值节点；响应最多 1 MiB。单个宿主最多消费 4096 个不同 requestId，重复 ID 拒绝，即使前次业务失败也不能复用。JSON 字段名不计入值节点数，但计入字节预算。参数本身只有浅层标量。CLI 按 LF 分帧并允许 CRLF，逐帧输出响应；超长帧、超过帧总数及非空 EOF 截断返回固定错误后退出。普通业务错误返回响应并继续。没有 HTTP、WebSocket、XPC、浏览器或原生 WebView。

请求 ID 去重是进程内协议保护；任务幂等由 PostgreSQL 持久键保证，重新建立宿主后仍有效。标签目标由服务端从幂等键推导，客户端不能选择任意目标或执行 SQL。任务 DTO 只投影展示字段，不暴露 payload、租约、数据库名或宿主绝对路径；不伪造核心尚未存储的更新时间。容量只为逻辑引用估计，physicalPool 始终 unbound。

资料库元数据不会授予内容访问。卷绑定、内容批准及读者变更不进入消息白名单；已有批准的 API 宿主可读取合成文件，新的 CLI 宿主默认没有卷及目录授权。文件名/文本返回普通数据，不能当翻译键或 HTML。静态页面仍显式使用内存 fixture。

JavaScript createBridgeAdapter 验证可序列化的普通 JSON、字节/深度/节点预算、相关 ID 和唯一结果字段；拒绝未知错误码、访问器、循环结构、非法数字及代理项。传输异常只变成 unavailable，没有 fixture 回退。它仍是 request 通用客户端，尚无完整业务 DTO 校验、生产超时/重连、DOM 接线或可靠传输。

Node 集成测试通过管道调用独立 macnas 子进程与私有 Unix socket PostgreSQL；只创建合成实例。它验证协议和真实数据库行为，不等同于浏览器验收、本机恶意进程隔离或生产安全通道。后续需分页、完整 DTO、身份/宿主信任设计及真实平台验收。
