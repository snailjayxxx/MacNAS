# ADR-033：管理执行预览与一次确认的呈现模型

日期：2026-10-17。状态：自动模型验收完成，提交推送以Git/外部发布收据为准。见[阶段证据](../evidence/n029-c3c4a-2026-10-17.json)。

先定义执行呈现边界，实际宿主与消息后续单独接线。context采用不同版本键及managed-execution purpose，固定选中声明/主体/模式和来源；只读账目/观察形状不能代替。预览固定ID、意图、声明/SHA及短时效，恢复固定entry；不重算PG规范意图摘要。

确认必须显式携带当前previewID和confirmed:true；在派发前本地消费，任何派发后错误保守uncertain且不能重试。预览时效从请求开始计算，支持单调小数时钟；旧nonce拒绝、并发拒绝、关闭清空/隔离迟到，回调关闭和异常不产生额外服务调用。三个授权/文件系统/容量释放标记恒false。

本地一次消费不替代宿主持久幂等与跨窗口消费；真实宿主仍要独立批准/来源、最终锁内复核和恢复目标批准。当前没有实际执行context/RPC/适配器或DOM，测试全部MOCK，不因已读取ID或匹配分类授权效果。见[模型契约](../contracts/MANAGED_EXECUTION_CONFIRMATION_MODEL.md)。

用户授权无新决定自动连续开发、中文提交及正常推送dev/bootstrap，浏览器已允许按需使用。旧迁移、原始规划和父需求保持；只在完整原生基线及实际内嵌依赖逐字节不变时明确复用，并执行新的前端/需求冻结。
