# ADR-028：Schema6 单物理合成树与持久文件身份

日期：2026-10-17。状态：自动验收完成。见[阶段证据](../evidence/n029-c3b-2026-10-17.json)和[验收矩阵](../plans/N-029-C3B-ACCEPTANCE.md)，提交/推送以Git及外部发布收据为准。

## 范围

C3A的Schema5只提供持久容量元数据。C3B新增0006/Schema6和一个空白、同设备、固定私有目录的TestLab范围，把有限接收、复制、回收及恢复接到同一份64MiB声明额度。0001–0005及Migration5保留原字节。

物理范围仅从全新空实例创建，不接管任意目录、既有文件、旧回收历史或另一个元数据范围。可见文件采用内部标准UUID名称，暂存位于私有host-binding目录；既有网页内存树和旧原生fixtures/volumes仍保持各自范围。没有容量RPC、执行消息、列表/DOM、正式NAS认证或大文件通道。

Schema6新增physical_capacity_scopes和capacity_file_ownership，完整数据库16表。前者持久固定注册摘要、设备、library/vault/staging inode及系统uid；后者在预留时创建空凭据行，owned时固定发布后的完整文件stamp、SHA及提交时间。Schema5账目格式及metadata_only字段保持原语义，物理资格由Schema6独立记录叠加，Schema5不能构造物理许可。

## 文件身份和容量守恒

SHA一致不能证明文件对象未被替换。owned对象必须同时匹配持久device/inode/uid/mode/nlink/bytes/mtime和SHA；回收、恢复的合法rename可以改变ctime，每次实际效果仍按当次完整前后stamp复核。相同字节的新inode不能被认领为原对象。

全部reserved、armed和owned共用64MiB，单文件0..16MiB，64条终身历史/8活动预留。回收或恢复只改变位置，原allocation始终owned且继续收费；entry回收费released不能释放整树额度。零字节占用历史/活动槽。

数据库的物理绑定和文件凭据进入UTC完整摘要、16表停写、严格列/约束/索引/10个函数及角色拒绝。容量和文件日志继续共用同一PG事务准入锁，并计入新增记录的最坏终态预算；armed后的有界终态写入不重新聚合可能增长的旧任务数据。

## 批准与一次效果

宿主批准固定purpose、原始主体、DB/宿主/实例/代次/注册，以及确切接收声明、复制来源allocation、回收allocation或恢复entry。批准是内存封闭对象，不可由ID、JSON或旧批准重建；重启须新批准。最多8个有期限许可，撤销不释放持久费用。

实际Instance共享gate、vault flock、根/祖先FD和当前作用域检查通过后才能得到封闭permit。接收/复制先持久预留全部字节，再arm，才创建O_EXCL/0600暂存；32KiB固定来源分块、完整SHA、文件fsync、一次RENAME_EXCL、双父同步及后置复核后构造现场witness。owned状态和身份凭据在同一PG事务写入；两行先锁定/检查，后续SQL失败必须回滚整个事务。

旧回收执行者通过独立封闭access接入同一flock和库存核对，固定内部UUID路径及恢复原名/根目录，来源/目标批准仍分别验证。旧无许可入口、纯MetadataOnly方法及普通可携在已管理范围拒绝；即使capacity宿主标记缺失，Schema6绑定仍阻止这些旧入口。

## 故障和边界

reserved只有在新批准、真实锁及可见/暂存两个路径均不存在的正面证明下才可取消。armed无论是否看到匹配文件都保留全部费用；不自动认领、重放rename、取消或释放。发布后缺owned凭据、未知名称、坏对象、活动文件日志或不一致库存均阻止新写，保留现场。owned的同键重试只返回原ID和记录，不再发布。

本切片不提供armed修复或受管理回收日志的写结算/取消入口，持久未知状态会继续阻止后续写入。诊断数据库快照只含元数据，普通portable拒绝任意范围/历史及已知物理标记；数据库回退不撤销文件效果。

新验证必须包括真实0/16MiB/满64MiB、上传复制竞争、回收恢复守恒、inode替换、撤销/权限/恢复模式/最后间隙、证明写入SQL失败、旧元数据增长，以及reserved/armed/afterPublish/owned四个真实SIGKILL检查点。另跑新未过滤全量、全部Schema6 CLI/16独立管道、实际Schema6 Node→Swift读取、无监听前端与需求冻结。当前Mac合成测试不证明macOS15运行、跨Mac、断电、物理池、生产规模或敌对宿主进程强fencing。按用户要求不启动浏览器/预览。
