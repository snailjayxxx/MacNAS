# ADR-Pool-001：固定聚合冗余池候选比较

状态：候选研究＋数学故障模型；真实盘验证 RED/BLOCKED，无可擦除测试盘。没有作任何盘集修改。

|候选|容量/最少成员|单盘故障与故障域|重建与损坏范围|扩容/迁机与缺口|
|---|---|---|---|---|
|A 两个拼接组组成镜像|min(sum(A),sum(B))；最小3盘可形成不等成员组合，目标验证至少5盘|任一成员损坏使该侧拼接组不可用；另一侧完整才可读。两个柜分别影响两侧则可能全池不可用|先核对UUID/布局/独立备份；替换容量不小于丢失成员，从完好镜像侧复制并全量校验；重建期间唯一完好侧再次故障可能丢全池|Apple文档给出拼接集参加镜像示例；任意5盘拓扑、APFS/ACL/xattr/加密和升级行为仍须实机。固定布局，扩容需备份/重建/迁移评估|
|B 独立镜像对＋统一资料库命名空间|sum(min(pair_i))；2盘/对，5盘通常2对＋备用|任一单盘容错；同一对两盘丢失则该对资料受损，其余对可保留|逐对替换/重建/校验；不能将其他对的完好状态冒充整个单一文件系统完好|它是多个文件系统，不完全满足统一容量池；只作对照，不能替代用户目标|
|C 自研固定条带单奇偶校验|(n-1)*min(D_i)，n>=3；例5×12TB理论48TB|一成员失效理论可重建；跨柜多盘失联超出一盘保护|必须有写洞日志、校验、错误盘识别、代际元数据、独立离线恢复器；没有这些时无法保证读取或写入损坏范围|开发及验证成本极高；当前没有块层实现，不能承载正式家庭数据|

`MirrorOfSpans` 仅计算A的容量、成员/柜故障可读性、降级阻写和替换容量。5盘模型逐一模拟单盘失效，并验证跨镜像侧柜故障超出保护。没有块设备、真实数据重建或磁盘镜像；不能称物理容错通过。

A的前置条件：明确硬盘柜是否逐盘可见、各盘容量和故障域；专用可擦除盘批准；至少一次真实降级/中断重建/替换错误盘/迁机/独立恢复和完整性验证；独立备份。条件满足前不最终选择布局。

官方依据（概念边界）：https://support.apple.com/guide/disk-utility/overview-of-creating-disk-sets-dskufd8dce72/mac 。RAID0/JBOD本身不满足一盘容错。
