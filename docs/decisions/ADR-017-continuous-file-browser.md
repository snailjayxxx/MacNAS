# ADR-017：有界连续文件浏览与窗口状态

2026-10-16，N-023。用户明确当前文件中心过于简单，应具有Finder式连续浏览，并参考DSM的完整NAS操作。N-020的三项/页验证界面没有达到这个目标。本阶段先完善只读浏览这一条用户流程，其他文件操作保持明确缺口。

## 决定

在既有directory-view来源与页控制器之上增加file-browser.js，不改变Swift页协议、卷批准、SQL、会话或后端目录预算。默认每次50项，已加载上限1000，历史64；来源仍由桌面显式提供。next累加页而不是替换，预览范围可含前页已加载项目，但来源仍逐次授权，文本上限64KiB。

浏览器只保存当前目录的有界元数据、导航历史、选择与展示设置；不递归扫描、不缓存所有资料库内容。上限前保守停止继续，明确仍有未加载项目。搜索/排序仅针对已加载项目，不能宣称全目录搜索或服务端排序。历史只存逻辑资料库ID及相对路径；本阶段不写localStorage，不影响可携实例格式。

导航先读取，成功后才提交历史与显示位置；失败保留原位置及标注的旧结果并要求重新读取，避免把旧行显示在新路径下。切换成功清理选择、搜索和类型过滤；排序偏好留在窗口内。新分支截断前进历史；窗口关闭清空位置/历史/选择，身份切换由既有桌面epoch与来源dispose隔离。

模型select支持单选、toggle和range；selectAll只选择当前可见项，过滤清理隐藏选择。预览绑定目录代次与选择代次；迟到结果返回null。模型借用来源，不关闭共享客户端或会话。

窗口采用资料库/当前已加载子文件夹侧栏、后退/前进/上一级/重读、面包屑、列表/图标、名称等排序、多选与详情。单击选择，双击或Enter进入目录/支持的文本预览。未支持预览的文件仍能选择并查看详情。选择时不重建文件行，以保留浏览器双击目标；导航、排序和过滤才重建列表。库授权集合改变时重建浏览模型，清理旧库历史。

未知目录大小、时间与资料库估计继续明确未知；文件名和内容按普通文字显示。没有上传、下载、改名、复制、移动、删除或回收站的假成功按钮。HTML仅增加file-browser.js，原有connect-src none及静态白名单边界保留；宿主客户端与通知核对模块均不向静态页提供。

## 验证与限制

纯模型覆盖历史分支/预算/错误、加载与选择、多语普通名称、排序未知值、旧页预览、撤权/恢复、超时与迟到结果。静态HTTP策略核对加载顺序、模块白名单和纯文字输出。代码检查和模型通过不替代实际DOM、双击、键盘、焦点、响应式或翻译质量验收；W/T/N/F全部仍待正规浏览器入口恢复。

没有生产NAS连接、大目录性能承诺、虚拟滚动、服务端全目录搜索/排序、通用预览或系统文件权限编辑。完成基础浏览后，交付应按用户工作流程补齐文件操作/传输及[DSM控制面板与网络对照](../plans/DSM-CONTROL-PANEL-NETWORK-REFERENCE.md)，不继续只增加后端小模型而搁置实际业务。
