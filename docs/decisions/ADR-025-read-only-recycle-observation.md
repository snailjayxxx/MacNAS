# ADR-025：只读观察与日志完成分开展示

日期：2026-10-16。状态：C1已实现并通过完整前端模型检查，见[阶段证据](../evidence/n029-c1-2026-10-16.json)。B1/B2执行协议不变。

数据库阶段、当前entry计量和文件观察是不同事实。candidateMoved缺持久post证据；matchedPost只表示当前观察匹配已有证据，observed/uncertain仍需当前独立新写批准结算。C1只验证并保存这三类数据，不把观察转换为completed或执行权限。历史completed recycle在随后恢复后可显示released，不能用旧operation phase推导当前计量。

严格投影只接受封闭字段、标准小写UUID、原始主体、JS安全整数及已定义词汇，不把FS身份或批准令牌交给视图。只读模型固定operation/可选entry与主体，在首个可见结果后固定不可变意图并拒绝revision倒退；无效/失败的新响应保留旧观察并标stale。它不认证宿主来源或新建连接，C2必须保留真实会话/实例/数据库范围并另行接线。

dispose只关闭本地视图，不取消/删除日志、释放字节或关闭借用来源；显式刷新无自动重试。同步回调关闭也须在读取前重新检查；迟到结果不能复活窗口。刷新返回值需在finally收尾后与最终snapshot一致，三项实际反例和20项定向测试随最终阶段证据保留。网页/DOM/实际浏览器未因纯模型通过而完成。
