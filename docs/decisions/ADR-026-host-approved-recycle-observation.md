# ADR-026：只读核对桥接的宿主批准与固定来源

日期：2026-10-16开始，2026-10-17完成自动验收。状态：已实现，真实PG/管道及本阶段新完整回归通过，见[阶段证据](../evidence/n029-c2-2026-10-16.json)。沿用B1/B2日志与C1模型，旧0001–0004不变。

新增宿主专用的observe批准，不向消息层提供签发入口。注册不授予读取，普通browse/copy/写批准也不代用。API会话须按原始UTF8唯一主体匹配当前管理员，固定API构造时的实例/代次/DB/宿主；Authority每次许可和读块再检查当前会话，结束/撤销阻止正在读取的旧许可继续使用。8个会话批准上限及只释放自己的替换清理维持有界，不触碰日志或载荷。

只读响应投影不携FS身份或能力。C1正文不变，桥接另包版本化来源context；每API随机nonce加会话/锚点/注册规范字节做域隔离、长度分帧HMAC，具名客户端固定首次有效标记，防止同样用户/版本的另一连接混入旧视图。标记不是登录/授权或强fencing；不支持跨重启自动认同/采用来源，新宿主仍需新批准及新客户端。相同API/会话/注册的明确重新批准保持来源标记。

read-only模型适配器固定借用的客户端；创建只查概览，显式刷新才请求核对。dispose不取消/删除操作、释放计量或关闭共享连接，迟到结果不复活视图。显式abort/超时仍按旧具名客户端政策关闭，不新增自动重连。unknown结果保留未知费用，matchedPost不等于completed或可结算权限。

保留4项实际早期草稿失败：错误revoke方法名、显式abort错误测试预期、Native投影缺少计量/分类约束的7个失败断言，以及只读let字段测试构造编译错误；真实定向另发现Native/C1错误耦合独立计数及RPC错误码测试预期，已修正并加入真实版本序列回归，实际4/2只读DB反例和模型红例均保留；修复、原始日志与所有后续真实运行见阶段证据，不把编译/模型结果冒充PG效果。
