# ADR-020：独立批准的有界单文件复制

日期：2026-10-16。N-027接续ADR-019；实际验证结果见[阶段证据](../evidence/n027-2026-10-16.json)。PostgreSQL18.6/Schema3不变，没有新依赖、网络监听或生产文件路径授权。

## 决策

先交付一个常规文件的复制：选来源 → 选有权目标资料库/目录及名称 → 冲突预览 → 明确确认 → 每次32KiB由宿主读源、写私有暂存 → SHA256核对 → 不覆盖发布 → 原结果查询及目录重读。来源永远保留。单文件最多16MiB，不支持目录、批量、跨设备、覆盖或移动。两个资料库可以不同，但当前原生来源、目标及实例暂存必须位于同一设备；跨设备明确拒绝，没有隐式回退。

复制目标要求宿主单独调用`authorizeFixtureLibraryCopies`，管理员、开发模式、readWrite绑定与既有内容批准同时有效；上传或mkdir/rename批准不授予复制权。来源只使用既有明确内容读批准。桌面只传逻辑资料库、相对路径和单名称，不接收宿主根目录或改变授权的消息。

预览固定两端的会话、用户原始字节、角色/模式、实例/generation、数据库、卷/介质/挂载/盘点修订、内容reader和目标copy批准。持有来源文件描述符和目标父目录；每块前后及发布前后再次核对。来源替换、原地修改、撤权、重批、父目录替换或实例改变使原能力失效。检测不等于文件系统快照或对敌对本机进程的强fencing。

## 生命周期和外部效果

独立复制注册表每API最多8个活动能力、64MiB暂存预留、32条短期终态；预览30秒、空闲60秒、绝对30分钟、结果300秒，按请求惰性回收。来源和目标一致的预览返回unchanged；冲突返回conflict，二者都没有提交能力。ready才登记能力；编码预览失败不登记。

确认仅创建私有暂存。`copyFileChunk`以原ID及期望offset推进一块，不让客户端提供或替换数据。仅最后一个相同offset可以明确重放，不能跳跃或从状态查询接管能力。空文件用offset=0执行最后一步。边复制边计算SHA256，再以固定缓冲重读暂存核对摘要；沿用0700暂存目录、0600常规单链接文件、NOFOLLOW/EXCL、完整写入检查和`RENAME_EXCL`。

发布前失败清理仍属于本次操作的私有暂存；未知/替换对象不删除。本次发布流程内的文件/授权核对、同步或期限失败为uncertain，保留目标与摘要；取消也不会删除已发布文件。响应编码或传输失败不改写既有回执，宿主可能仍为completed，应查询原copyID核对。相同ID不重复发布，失败响应不能自动新建复制意图；原宿主仍在时只读核对。notVisible不证明没有外部效果。

这些能力、预算和结果只存在于本宿主内存，不是持久文件任务、审计、崩溃协调或重启恢复。崩溃孤儿暂存仍保留；后续若交付恢复，必须使用新的版本化Schema迁移和外部效果日志，不改0003，不套用数据库事务内exactly-once说法。

## 合成网页与客户端

扩展前先补共享内存树总字节配额：所有资料库的初始UTF8文本、已发布二进制、上传及复制在途完整预留共同受64MiB上限约束；发布把预留原子转换为已发布计量。失败/取消/到期只释放未发布预留，不减少已发布字节；会话结束或目录来源dispose清理该合成树。4096条目上限和原有单文件/在途限制同时生效；这不是生产磁盘剩余空间或跨进程配额。测试可收紧配额，不能放大上限。

具名客户端为原意图和进度保留有界记录，同ID串行。关闭窗口或来源时尚未返回的上传预览、下载头及复制预览必须在返回后尽力取消并释放本地所有权；来源dispose也清理已有自有能力，同ID在途操作结束后再清理，陌生状态观察不登记所有权。共享连接保持由身份所有者管理，不通过重连或放大预算掩盖泄漏。连接丢失时不假装宿主已取消，等待期限或宿主退出清理；取消失败保留不确定语义。普通状态观察不授予复制、读写或取消权。

网页从现有目录来源逐页选择目标文件夹，保留原来源/目标、确认、进度、取消与核对入口，完成后重读匹配的当前目标目录。普通文件名/路径用文本节点。`file-copy-view`的元素替身测试只覆盖结构和回调，不证明浏览器焦点、键盘、布局或实际操作通过。网页仍只操作明确合成内存树，原生与真实Node→Swift管道另在批准的新建APFS目录验证。生产浏览器通道仍未实现。

## 验证边界

新增FC01–FC06与原46项共52项浏览器用例保持未执行；没有新权限状态时不重复访问、不换通道。合成测试和当前Mac不能替代真实NAS、macOS15运行、跨Mac、物理盘/断电或大型文件验证。下一阶段继续可恢复回收站、移动、共享权限与独立只读控制面板适配器；SYS-09远控仍很后期。
