# ADR-005：静态网页桌面与业务适配边界

日期：2026-10-15（Asia/Tokyo）。状态：实现采用；浏览器验收待完成。

P03先建立无框架、无构建依赖的中文/日文网页桌面。HTML、CSS、JavaScript和自研SVG图标直接保存在web/dist；该目录是可审阅源码，不是编译产物。页面永久提示合成数据及NAS未连接，显式使用内存fixture；没有外部字体、图像、脚本或新增npm包。

桌面提供启动器、应用窗口、任务、通知、文件样例和偏好。35TB仅为合成逻辑引用，物理池未绑定；两个套件是既有可信样例，不能据此声明第三方安装器或OS沙箱完成。任务进度只描述已知检查点；没有后端尚不支持的暂停/恢复/手动重试操作。

适配层每次检查会话、角色、资源和受众；恢复模式拒绝提交、取消、事件轮询和确认，因为轮询会更新交付游标。此为模型验证，不能防止浏览器拥有者修改JavaScript，也不是生产认证。界面隐藏按钮不构成安全边界。

仅语言、主题和窗口几何保存到浏览器偏好；业务状态、会话和消费状态保留内存，刷新重置，不进入可携实例。正式业务数据继续只使用PostgreSQL 18。身份切换清除旧窗口/缓存，并通过epoch丢弃旧异步响应。

未来桥接采用版本、请求ID和固定方法白名单。桥接缺失、协议不符或业务拒绝直接报错，不自动切回演示数据。当前仅未接线的消息契约，尚无Swift传输、生产认证、HTTP API或后台工作者。详见[DESKTOP_API](../contracts/DESKTOP_API.md)。

用户已授权本轮临时只读127.0.0.1:8766静态预览及浏览器访问。脚本核对开发盘身份，仅开放七条静态路由；两次已启动的预览均关闭。授权不扩大到真实NAS服务或公网。

自动模型和静态HTTP策略测试通过；浏览器先拒绝file协议，再对HTTP返回用户拒绝、保存的阻止设置。两次明确同意仍未解除工具限制；Codex内置浏览器检查返回Browser is not available: iab。没有绕过阻止，没有视觉截图或浏览器交互通过证据。P03与N-011继续保留未完成状态。

## 后续远程排查

后续远程排查：用户不在Mac mini旁并要求代改设置。原生工具明确禁止操作com.openai.codex自身界面；随后只读状态检查返回apps/browsers均为空，并报告Sky Computer Use native pipe startup failed。当前工具没有浏览器站点权限修改接口，因此未修改任何Codex权限、未启动新预览，也未绕过既有阻止。官方Browser文档提供codex://settings/browser-use直达入口；Remote connections说明远程会话沿用宿主权限与浏览器配置，但未提供本任务可调用的远程站点权限修改接口。用户无须重复授权或现在回到Mac mini，先继续不依赖浏览器的代码工作。
