# ADR-006：逻辑卷身份与合成绑定生命周期（N-012）

2026-10-15，Asia/Tokyo。范围为注入式合成清单和宿主内存授权，不查询、卸载或写入真实磁盘。

保留可携VolumeReference的libraryID、volumeID、相对目录和容量引用；新增观察值区分卷UUID、介质UUID、挂载会话UUID、显示名称和柜ID。名称不参与身份匹配，UUID重复时不选择任意候选。系统卷、缺少授权和只读卷的写权限分别拒绝。清单中的authorized只是fixture输入，不能作为真实TCC、磁盘或所有者授权证明。

管理员在PrototypePlatformAPI发起预览，提交核对同一会话、完整预览、30秒时限、清单修订及显式fixture确认值。令牌失败即消费；最多保留128个有效预览，过期回收。清单至多1024项。令牌不是生产认证或系统操作审批。

显示名变化保持现有绑定；卷消失、重复身份、介质替换、重挂载或授权丢失会撤销旧绑定。后来恢复原UUID/名称也不能自动恢复，必须重新预览和绑定。柜掉线使用一次清单更新移除多个成员，未受影响的成员保持绑定。只读介质变化立即限制写权限。

绑定、待确认令牌、资料库读者授权和文件句柄均为宿主进程内状态，退出/重建API即需重授权，不作为业务数据库回退。PostgreSQL仍为唯一业务持久引擎。逻辑引用外部变化时旧registry拒绝继续；导出只带原逻辑引用，恢复不带卷授权、宿主路径或目录句柄。

对外API均带Fixture前缀，只有合成开发模式管理员能注入清单、提交绑定、撤销及授予读者。恢复模式不允许扩大这些权限。实际OS枚举、稳定硬件身份来源、热拔插监听、安全卸载、盘健康、真实卷授权及池fencing仍未实现。旧任务队列的MountedVolume注入接口仍为既有合成测试接口，不能因此声称所有真实磁盘写入已受保护。

结果与限制见N-012/N-013验收及结构化证据。P04和父需求不标为整体验收完成。
