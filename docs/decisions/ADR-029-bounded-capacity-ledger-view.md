# ADR-029：有界容量账目只读模型

日期：2026-10-17。状态：自动模型验收完成，提交推送以Git和外部发布收据为准。见[阶段证据](../evidence/n029-c3c1-2026-10-17.json)。

C3B建立了单个新建Schema6物理合成范围的持久账目及文件凭据。后续列表应先明确它展示的证据等级，避免把数据库owned状态当作现场文件匹配，把64MiB减去账面费用当作磁盘可用空间，或把只读范围标记当作执行批准。

本切片先提供严格、有限、完整的账目投影和本地读取模型。最多64条终身历史、8个活动预留、64MiB总声明量和16MiB单文件与Schema6一致，零字节照样占槽。六项聚合须与全部可见记录一致；响应要求原始UTF8主体及固定不透明sourceID等值。sourceID的宿主生成器仍待后续实现，不作为认证或执行许可。

同一模型约束不可变声明、单调revision和有限状态前进；失败保留旧列表但标记过期，关闭则清空当前列表并忽略迟到结果。创建和关闭都不隐式执行宿主请求，不自动重试、续做、认领、取消或释放费用。

实际审查保留三类反例：初轮22项中，reading回调关闭后仍发出了读取（21通过/1失败）；修正后追加来源与关闭清空检查，24项中22通过/2失败。修正显式sourceID绑定及dispose清空当前视图后，新增两项来源变化检查，26项全部通过。原始失败日志、源码快照及修正过程保留在仓库外Evidence；不得把MOCK当作真实宿主证据。
