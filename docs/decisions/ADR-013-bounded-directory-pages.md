# ADR-013：有界目录扫描、变化标记与继续令牌

2026-10-15（Asia/Tokyo）。N-019扩展已明确批准的合成资料库读取，保持PostgreSQL 18、Schema 3及原有业务表不变，不添加依赖、文件修改方法、监听或生产授权。旧listFiles/listFixtureLibrary仍为完整数组或超预算拒绝，最多1000项，不静默截断。

新增fixtureLibraryPage及桌面第12个固定方法listFilesPage。默认每页50、范围1至100；按实际返回名称的原始UTF-8字节顺序，名称不按语言或Unicode规范化排序。参数仅libraryID及可选relativePath/pageSize/cursor；相对空路径表示库根，不接受任意宿主路径、排序、授权、角色、卷清单或数据库选择。

每次读取重新打开独立目录描述，保留已有逐级openat/O_NOFOLLOW、设备/类型/链接数和批准路径复查。扫描全目录以检查危险条目及规范化/大小写名称碰撞，再选出after之后最小的pageSize+1个候选；最多保留101份候选元数据，不建立完整目录DTO缓存。碰撞检查只保存名称规范化后SHA-256摘要，摘要碰撞也拒绝，不保留完整名称集合。

扫描明确受8192项、原始名称共1MiB、单调5秒的固定预算限制，超限整体拒绝，不能把首批或已挑选结果冒充完整页。每项仍做fstatat，不跳过不安全名称或页外的符号链接、硬链接、特殊文件、跨设备条目。预算不接受客户端覆盖。算法每页重扫，候选插入最多约O(N×pageSize)比较；摘要集合仍随扫描项数增长至8192的固定上限，并非常数内存或千万文件吞吐设计。需要支持更大目录时应另行设计索引/持久枚举等机制，不擅自扩大预算。

5秒检查在同步系统调用前后执行，JavaScript/宿主另有既有等待预算；这不是可强制中断所有文件系统I/O的OS硬超时。当前只在合成APFS目录验证，不承诺故障设备、真实远程挂载或生产延迟。

目录标记包含device/inode/mode/size/link count及纳秒mtime/ctime，只保存在宿主。第一页固定标记，继续页要求相同；扫描前后、候选元数据、批准路径以及编码后再复查目录，检测新增/删除/同名替换/目录替换及当次候选的修改。检测到变化返回staleState，要求从头读取；不偷偷跳过或把旧位置挪到新目录。它是基于文件系统标记的变化检测，不能消除检查后的竞态、时间戳粒度/复用等限制，不是事务快照或真实卸盘/fencing证明。

普通文件原地修改未必改变父目录标记，后页因此可见新的大小/mtime；文件元数据按读取时返回。consistency固定为directory-stamped-live-metadata，不能称为全部文件内容/元数据快照；本方法也不读取文件内容。整个页完成前对所选候选再核对一次元数据，之后仍可能变化。UTF-8路径最多4096字节/128段，不暴露绝对根、文件描述符、inode、摘要集合或内部标记。

继续令牌为宿主随机小写UUID、内存一次性能力，不接受外部after名称。绑定API注册会话、实例/数据库身份、用户原始UTF-8、角色/模式、资料库/相对路径、页大小、卷/介质/挂载ID、卷批准ID/清单修订和内容reader身份。内容重新批准、清单修订、模式/身份变化不能沿用旧链；无关清单修订也保守拒绝，不承诺最小失效范围。源API重建、重启或恢复均没有原目录批准/令牌。

每API最多64个待用令牌和64个消费墓碑，从首次请求起整条链60秒单调期限，继续不续期；退出清理该会话待用令牌。不同会话/参数/批准范围拒绝且不消费所有者令牌。已知过期expired、保留墓碑重放replay、未知/已清理denied，格式错误invalidInput。检测到目录stale的查询丢弃该旧位置。其它查询/授权/编码/响应预算失败不消费；验证/编码后再次核对授权与期限，成功才登记下一枚并消费旧令牌。成功响应若传输丢失，令牌可能已消费，必须显式重读，不自动重试或保证分页幂等。

卷/读者授权与会话在扫描后及编码后再次验证，内容reader重新批准也失效。恢复只读可使用同进程已有目录批准进行查询，不写数据库消费位置；新恢复实例仍无批准，不能自动扩大授权。宿主序列化本注册表的扫描/编码，原型取舍不等于并行吞吐设计。令牌只保留上下文、末名称和标记，不另持有目录流/文件句柄；内容reader的既有批准句柄仍由内容注册表管理。

wire页恰好为{pageVersion:1,order:"name-utf8",consistency:"directory-stamped-live-metadata",libraryID,relativePath,pageSize,items,nextCursor}；末页nextCursor显式null，继续页为满页。items沿用普通name/relativePath/kind/bytes/modifiedAt，字节数必须是JavaScript安全整数。无total、全局搜索、上一页或目录快照承诺。

具名客户端listFilesPage严格校验精确元数据、相对路径关联、普通文件/目录、安全数值、页内名称碰撞、UTF-8页内/跨页递增；最多保留64条继续链，独立于任务游标预算，同一令牌串行。stale/expired/denied/replay/missingVolume移除本地位置，等待显式从头读取。discardFilePage只释放本地所有权，无RPC，不减少宿主预算；宿主仍按容量/期限清理。关闭清空并拒绝迟到响应，没有自动聚合、重连或fixture回退。

静态页面继续内存fixture，HTML/白名单/CSP和DOM不接入本接口。W01–W10、T01–T08、N01–N06及完整浏览器清单全部等用户回家；不启动预览/尝试设置。测试结果见[N-019验收范围](../plans/N-019-ACCEPTANCE.md)和[结构化证据](../evidence/n019-2026-10-15.json)。没有生产身份、大目录索引、真实NAS/物理盘、macOS15运行或跨Mac验收。
