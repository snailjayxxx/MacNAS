# ADR-011：任务当前页展示、适配与窗口生命周期

2026-10-15（Asia/Tokyo）。N-016已有真实任务页与统计，本轮把静态网页的任务展示调整为当前页读取。Swift、SQL、Schema 3和核心测试保持原字节；不新增依赖或业务监听，不恢复浏览器访问。

task-pages.js提供显式的createFixtureTaskSource(api, session)及createClientTaskSource(client)。后者只接受调用方已创建的具名客户端，不创建传输或fixture回退。两者先固定来源、用户、角色及模式，再投影任务和统计。统计来自overview，与当前页数量独立；上下文变化撤销来源。close拥有该fixture会话/具名客户端的生命周期，窗口控制器dispose只清理本窗口，不关闭共享来源。

展示任务为固定字段：id、name、kind、state、attempts、maxAttempts、revision、steps、lastError。name明确区分普通text与固定key：标题恰好为jobHash等字样时也只显示文字；只有白名单样例名称才进入词典。raw payload、幂等键、租约、路径和updated不进入视图，steps只表示既有两步检查点，不补造更新时间或物理容量。真实客户端继续承担完整原始DTO校验，展示层检查必要状态/受众并投影；fixture原始任务允许其历史演示字段，不宣称其原始数据就是生产DTO。

createTaskPager默认50、允许1至100条，只保留当前页，不收集历史页。网页演示固定每页3条，首页另外只保留2项预览；原“最近任务”改为“任务预览”，解释编号排序。搜索和状态筛选只作用于当前页的名称/编号，并持续提示范围与实时语义。提供下一页和重新读取，没有可重放的上一页游标或自动遍历。第一页与后页的统计/内容不是一致性快照。

控制器有idle/loading/ready/mutating/error/closed状态，同一控制器一次一个请求。翻页成功替换页并检查跨页ID递增；错误保留上次读取的页，标记requiresReload、丢弃继续位置、禁用旧列表的取消操作和继续，等待显式重新读取。独立新建任务仍按当前来源的身份/模式权限判断，不依赖旧游标。重读立即清空旧页并从头开始；空页、末页、无本页匹配分别展示。未知异常只显示unavailable等固定码，不暴露诊断。

取消只接受当前页任务，使用服务端确认的终态替换该行，保持页号和下一位置；随后独立刷新概览/预览。取消返回completed/failed时显示状态已更新，不能一律宣称取消成功。失败可能已提交，不自动重试或假定回滚；明确重读后才能再次取消旧列表中的任务。创建保留该操作的业务标识，成功后从首页重读，按编号排序可能仍需下一页才能看到新任务。

关闭窗口dispose立即清空任务、废弃代次。迟到页/取消结果不能重填旧窗口，迟到页的新继续令牌尝试释放；关闭窗口不会关闭共享客户端。身份切换先撤销旧模型和来源，再建立新会话，不把旧用户内容带入新窗口。页面还对窗口对象、刷新序号和模态框实例作检查；这些DOM接线经源码/语法检查，真实焦点、事件、布局与可访问性仍待浏览器实测。

新增具名客户端本地discardJobPage，只删除本客户端对已见游标的所有权；不发RPC、不撤销宿主内存令牌。进行中的游标不能先删，完成后再清理。宿主的128待用上限及60秒整链寿命仍生效，快速反复重读可能达到宿主预算，不能靠本地丢弃提高它。fixture提供同名本地方法实际释放其内存令牌；两者资源语义差异明确保留。fixture新增版本化页、UTF-8排序、会话/页大小绑定、一次性、过期及容量，仍是合成内存模型，不声称SQL执行或生产规模。

HTML/静态白名单仅增加task-pages.js，加载顺序为model、i18n、task-pages、desktop。bridge-client.js仍不加载/不静态提供；connect-src仍为none，无HTTP/WebSocket/NAS连接。可信具名客户端适配只在Node/已有stdin/stdout管道验证，不能把静态网页称作已连接Swift/PostgreSQL或生产登录。

测试覆盖模型、页上限/空页/末页、实时变化、搜索范围、普通标题、错误/撤权/过期、关闭及迟到响应、本地释放、真实管道投影/取消、读者及只读恢复。N-016全量186项核心收据通过完整38份源码摘要复用，本轮仅额外运行明确标注的解析器过滤和全部CLI/扩展管道，不能冒称又跑了186项。网页新增T01–T08与W01–W10全部待用户回家实测；本轮没有浏览器、截图或实际DOM通过证据。
