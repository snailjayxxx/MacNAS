# ADR-004：持久任务、租约及事务事件队列

日期：2026-10-15（Asia/Tokyo）。范围：当前 Mac 的合成实例，PostgreSQL 18；没有后台系统服务或网络监听。

## 任务与恢复

Schema 3 扩展 jobs，并增加 job_steps、job_events、event_clock、event_consumers、event_receipts。历史任务保留为 legacy，不由新工作进程领取。内置任务只包括写测试标签、写套件私有状态、读取 host-binding/fixtures 中不超过 1 MB 的合成文件并记录 SHA-256；没有任意命令或任意 SQL 任务。

领取使用 FOR UPDATE SKIP LOCKED；租约 UUID、到期时间、尝试次数和检查点持久化。租约时间以数据库 clock_timestamp 为准。续租、检查点和结果提交均核对数据库身份、当前运行状态、租约 UUID 和有效期。过期工作者不能在新工作者接管后发布结果。任务级租约不能充当跨 Mac 存储池 fencing。

任务分为准备与提交两个步骤。准备结果持久化后，重启直接使用该结果；最终数据库效果、完成状态、步骤和事件在同一事务提交。失败后使用有上限的指数 backoff；超过尝试次数终止。逻辑卷缺失进入 waiting_for_volume，不消耗工作尝试；仅测试注入的逻辑卷清单用于此轮验证，没有实际卸载磁盘。

取消立即使租约失效；已提交的任务效果不撤销。取消、完成及重试的先后顺序由数据库事务确定。进程崩溃后可重新领取，但没有跨文件系统或网络副作用的 exactly-once 承诺。当前内置任务的写效果全部在同一个数据库事务内。

## 事件与消费游标

每个状态转移及步骤检查点与事件一起提交。event_clock 的单行事务锁一直持有到提交，序号由事务更新分配，因此未提交的小序号不会被已提交的大序号跨越。原型用串行状态转移换取容易审计的顺序，不作大型队列吞吐承诺；后续需要规模测试与分区设计。

事件交付是至少一次。poll 持久记录已交付上界；确认只能推进到该受众已交付的事件。确认游标和唯一 consumer_id/sequence 收据同事务提交；确认重复不增加收据。崩溃发生在外部消费者执行效果与确认之间时仍可能重放，消费者必须幂等处理自己的外部动作。当前没有事件清理、订阅推送或真实通知渠道。

用户只能查看、取消和消费属于自己的任务。管理员提交平台标签任务；读者不能提交写标签任务。套件票据只触达该应用的任务、事件和私有状态，不能选择用户受众、核心表或另一个应用。消费者 ID 一经建立即绑定受众；会话退出、票据撤销或失效后业务 API 拒绝访问。工作进程是可信核心；已授权入队的数据库任务不持有临时票据，也不因 UI 会话到期自动取消。

## 迁移、停写和边界

Schema 2→3 在迁移协调器的新候选库内执行；旧库和签名快照保留。内置版本化 SQL 增加固定默认值，导入后的源版本语义摘要与升级默认值都要核对。失败事务回滚，提交先于 journal 推进时可重试。新表全部纳入 SHARE 停写、逻辑导出和语义摘要；时间数据统一按 UTC 表示，避免宿主时区改变摘要。

只读恢复保留任务、检查点和消费者游标，但不允许领取、确认或写结果。旧库的 JobLease 绑定旧数据库名，不能用于新候选库。正式接管前的租约重置、真实认证与主机授权仍属于未来接管流程；生产 cutover 继续拒绝。

本轮不证明断电耐久、跨 Mac、真实掉盘、OS 沙箱、生产认证或规模性能。私有 Unix socket 和合成身份沿用 ADR-003 的限制。

依据：[PostgreSQL SELECT 与 SKIP LOCKED](https://www.postgresql.org/docs/18/sql-select.html)、[事务隔离](https://www.postgresql.org/docs/18/transaction-iso.html)、[clock_timestamp](https://www.postgresql.org/docs/18/functions-datetime.html)。

当前任务ID、幂等键和消费者ID为实例数据库内全局唯一。客户端应使用不透明的唯一请求ID；受众之间碰撞会拒绝复用，不返回另一个受众的数据。后续多租户规模设计需评估命名空间与配额。

后续N-021增加[消费位置只读查询](ADR-015-read-only-event-consumer-status.md)，读取现有表的受众ack/delivered而不写消费者或推进位置，恢复可读。它仍不提供跨连接来源证明或通知旧批自动核对/清理；历史N-018断连视图保持未解决，不能把新查询当作已完成安全重连。
