# 给所有者：MacNAS v0.6执行方式

你准备的工作：**只自行完成**外置500GB SSD格式化为普通APFS、取名`MacNAS-Dev`，并把本包传给Mac mini上的Codex。Codex会检查卷是否已正确就绪，随后自行建立目录和本地Git仓库、调查开发工具、编写框架和测试。不要求你手动先配置Git、Xcode缓存、Swift目录等。遇到macOS授权弹窗和危险系统操作时仍需你明确批准。

你新增的核心诉求：**以后把一份`MacNAS-Instance`实例文件夹打包复制到另一台Mac，安装好环境并走一次迁移向导，就能恢复大部分NAS平台设置、套件及应用数据。** 新Mac的系统后台服务、共享账户、访问授权、Keychain及磁盘绑定则通过安全向导重建；不会绕过苹果保护机制。正式照片、视频等30TB以上大容量文件可能在原独立存储池里，需要整柜移机或独立备份恢复，不会自动塞入一个500GB文件夹。

需求范围从v0.5的110项变成v0.6的111项：**97首版、13后续、1暂不需要**，新增`MIG-05`。这不是宣称功能已经开发出来；接下来由Codex进行真实代码开发并记录证据。

**安全规则**：不能让Codex自行再次格式化磁盘、修改旧群晖或现有Mac的正式共享、给任意可写文件夹里的程序提root权限、未经批准安装后台daemon、下载未经审核的第三方代码或公开服务端口。没有可擦除的测试盘，RAID测试只能使用模拟和只读研究。
