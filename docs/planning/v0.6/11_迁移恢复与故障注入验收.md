# 11｜MIG-05跨Mac迁移验收用例与证据矩阵（首版硬门槛）

所有实验先使用虚构用户和合成数据，在独立TestLab；没有另一台真实Mac则把E2E真机状态标未执行，不能伪造通过。

|用例ID|测试场景|成功条件|允许的首批环境|
|---|---|---|---|
|PORT-01|实例根整体改名/移路径/另一SSD位置|登录配置、插件元数据、数据库、任务策略重建；无硬编码旧路径|两个临时目录|
|PORT-02|旧、新机器UID、用户名、主机名及挂载位置不同|迁移能识别host-specific字段并提示再授权；不误授旧Mac权限|模拟两Host Profile|
|PORT-03|复制前数据库仍有WAL和任务在跑|使用事务一致性export；恢复后完整性校验通过且任务不重复写入|合成SQLite与任务|
|PORT-04|导出中途断电/导出目录不完整|manifest校验阻止启动，不覆盖上一有效实例；重试可恢复|模拟中断|
|PORT-05|插件包含数据库/schema差异/目录外路径|插件数据保留并迁移，失败可回滚或disabled，不丢原件|2自研样例|
|PORT-06|Keychain/TCC/系统账户未授权|目标只读可看诊断，不泄露明文密钥，不自动放宽权限|Mock Host Auth|
|PORT-07|真实卷没连接/同名假盘/卷UUID变化|阻止读写并显示原卷提示；禁止写入系统盘同名空目录|模拟盘清单|
|PORT-08|原Mac未停机，新Mac试图接管共享存储|目的端拒绝写入，显示竞争来源与接管条件；假锁不能绕过|模拟租约失败|
|PORT-09|新Mac迁移完成、旧Mac回退|只有一个实例获得写入许可，回滚不损坏已经写入的数据并能声明何处不可逆|模拟切换事务|
|PORT-10|目标OS为macOS15、未来更新OS的能力差异|不受支持的套件明确禁用/降级，核心配置完整|兼容矩阵mock；之后实机|
|PORT-11|新Mac重新注册LaunchDaemon/TCC/SMB|只在明确用户批准后安装受保护服务，ACL/SMB可真实读写且拒绝权限有效|**后续真实Mac授权测试**|
|PORT-12|实际5盘+跨Mac重连聚合池|新主机识别成员与池元数据、一盘故障恢复测试、数据校验且源已停写|**专用可擦除测试盘授权后**|
|PORT-13|容量巨大但只导出portable状态|导出清单列出未包含的30TB+照片视频/备份，并给出原盘重新绑定/独立复制选项|纯逻辑测试|
|PORT-14|用户不清楚是否完成迁机/误点返回|向导展示Preflight/Exported/Imported/NeedsAuth/ReadyForCutover/Active/Rollback状态；重试幂等|纯前端+业务模拟|
|PORT-15|文件夹或签名被篡改|hash签名/包来源校验阻止执行，并保留旧版本可诊断|模拟篡改|
|PORT-16|MacNAS-Dev SSD离线、意外挂载同名其他盘|开发/生产服务不会在内置盘同名路径重新生成或写入；日志不泄露文件路径细节|只读+模拟事件|

### 证据模板
`case_id; revision; source_os; target_os; source_machine_class; target_machine_class; source_instance_path; target_instance_path; synthetic_data; binary_versions; app_versions; test_command; real_disk_ids_redacted; privilege_state; observed; expected; status; rollback_result; owner_approval_id`。

**状态定义**：`NOT_STARTED / MOCK_PASS / LOCAL_MAC_PASS / CROSS_MAC_PASS / PHYSICAL_POOL_PASS / BLOCKED / FAILED`。`MOCK_PASS`不可作为`CROSS_MAC_PASS`或`PHYSICAL_POOL_PASS`。

### 发布门槛
最迟首版GA发布前，PORT-01–16中适用测试均有实际证据，任何安全/数据损失关键用例失败必须阻止正式发布。测试硬件或签名未满足时发布状态只能是alpha/原型并展示未验证范围。迁机不需要反复手动重建插件或导入逐个数据库，但必要macOS授权仍需用户完成。
