# 06｜不可逾越的操作门槛与验收

## G0–G7 操作门槛
- **G0（已满足，文档）**：阅读需求、核对哈希、技术研究、纯文本/源代码规划。
- **G1（MacNAS-Dev非破坏性开发授权）**：确认卷实际是外置APFS、名称精确为MacNAS-Dev且非系统盘后，允许在其新建项目工作目录、Git本地仓库、代码、fixture与自动化模拟测试。不允许格式化任何盘、覆盖同名已有文件、建立或推送未授权远端。
- **G2（有限只读查询允许）**：用户已委托Codex完成开发环境，允许只读 `sw_vers`、`uname`、`xcode-select -p`、`diskutil info /Volumes/MacNAS-Dev`、`df -h` 等基本环境及目标卷探测；只返回必要摘要，不扫描其他用户文件、私人目录或网络设备。越界读取仍需授权。
- **G3（逐次确认）**：Mac安装后台服务、应用权限、改变安全策略、接入系统共享与用户、启动网络监听。
- **G4（逐次确认）**：创建/修改真实SMB共享、Time Machine目标、目录ACL、真实文件传输、批量扫描用户数据。
- **G5（强批准+物理隔离）**：磁盘集创建/格式化/重建、故障注入、擦盘等。只能使用点名列出UUID/序列号并明确可销毁的专用测试盘；当前**没有**。不得将挂载的生产卷作为模拟目标。
- **G6（逐次确认）**：绑定已有域名/公网入口、配置证书、反向代理、第三方账号/手机/摄像头、网络端口暴露。
- **G7（单独审核）**：引入第三方运行时代码、模型、插件、媒体二进制、系统扩展；或发布包含这些内容的安装包。只允许先提交依赖清单、来源/许可证/校验/安全维护成本。

|权限|平台账户与SMB账户映射、访客上传拒绝、跨用户读取禁止、ACL继承、符号链接/硬链接逃逸、长路径与Unicode|

## 证据字段（每项任务必填）
`requirement_ids; task_id; git_branch; base_head; changed_paths; build_command; test_command; test_results; test_environment; actual_macos_version; real_hardware; dependency_approvals; system_operation_grants; rollback; known_risks; owner_decision_needed; status; next_task`。

已写单元测试!=已运行；测试通过!=Mac真机通过；模拟盘!=物理容错验证；“支持录像协议”!=已连接厂商私有摄像头；“可以同步”!=Windows/iOS客户端已经完成。

## 未达门槛时的处理
使用 `BLOCKED` 状态；继续其它不依赖的开发任务，交付「为何阻塞/证据/影响用户目标/可选替代/需要哪种批准」报告；不得悄悄删减目标，更不得以替代体验冒充已完成。

## v0.6 补充的迁移门槛
- 用户表示未来可以格式化并命名开发 SSD，不代表此步已完成；**Codex一律不得执行diskutil eraseDisk/eraseVolume/RAID create等格式化行为**。
- 原生受信任安装/更新器必须在受保护系统路径安装需要特权的辅助组件；**不能从任意可写外置目录直接执行root helper**。
- 导出时应先生成一致性快照，验证hash/manifest，输出目录范围与排除项；默认不打包用户照片/视频原件以及Keychain明文。新Mac恢复前检测本机服务/授权冲突和卷身份。
- 系统账号、TCC、Keychain及macOS服务注册不属于可复制目录中的万能许可证；只能经正规途径重新授权/绑定。
- 源实例仍在运行或仍占有同一磁盘池时，目标默认只读，不得以“迁移成功”为由启动写入。
