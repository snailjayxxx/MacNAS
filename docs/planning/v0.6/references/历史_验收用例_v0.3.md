# 验收用例与未决事项 v0.3

本文件全部是拟议验收任务，未在任何Mac、Windows、iPhone或硬盘上执行。只能在获得对应授权后的测试环境运行。每次测试输出实际平台、样本、步骤、命令、结果、日志、校验和、清理和失败点。

## 跨模块关键用例

### T01 同名盘与掉盘写入

需求：STO-02/STO-03。  
场景：使用两份不同卷身份的可销毁样本；注册其中一卷后卸载，再挂载同名另一卷。

预期：任务停止并显示资源离线；不写系统盘或错误卷；人工重绑定受控。

证据要求：去敏日志与实际状态；涉及数据时给出前后清单/校验；涉及权限时给出允许与拒绝用例；不得以“未报错”代替通过。

## 性能与兼容矩阵要求

禁止填虚构“占用低于X MB”或“百万照片秒开”。测试前由实际环境确定空闲/索引/转码/重建预算；记录CPU、内存压力、IO、并发任务、文件数量与版本。大库任务需可暂停，健康失败需解释原因。

兼容性以“支持并验证”“实现但未验证”“不支持/有缺口”分栏。Mac系统版本、Intel/Apple Silicon范围、Windows版本、iOS版本、磁盘格式、硬盘柜/USB桥、相机流协议、浏览器分别记录；不以一个“跨平台”词覆盖。
